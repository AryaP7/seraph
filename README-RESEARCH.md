# SERAPH Research — start here

This is the separately authorized working copy. **Hawkes, RMT and Hamilton are
retained.** The original project in Downloads was not edited. The new pipeline
runs offline from the copied research snapshot and has a local dashboard.

## What the evidence says

The mathematical repairs and forecasting pipeline work as software. **The
original claim of dependable advance crisis prediction is not established.**
The three-pillar-plus-volatility model still misses COVID before the project's
2020-02-20 onset date. It also misses the other assessable event labels; GFC is
unassessable because the model lacks enough earlier out-of-sample calibration.
Tariff-2026 remains an unresolved label, not validation evidence.

There is a concrete, narrower counterfactual: a generic external watch following
each new WHO health emergency declaration would activate on **2020-01-31**, 14
observed sessions before that COVID label. All nine declarations through the
snapshot cutoff were tested; eight produced no matched project crisis. This
rule was designed with hindsight, exact historical publication timestamps are
incomplete, and its warning must be credited to public external information.
It does not prove the original pillars predicted COVID.

For the separate future-loss target, combined Brier score is about **0.0695**
versus **0.0698** for the volatility logistic baseline. The paired difference's
descriptive bootstrap interval crosses zero. That is insufficient evidence of
a reliable gain. The loss target is a 10% decline from today's close at any
close over the next 15 sessions, not a named-crisis forecast.

Read [market-model results](research_results/v1_verified/REPORT.md),
[external-watch results](research_results/v1_verified/HAZARD-REPORT.md), and
[design decisions and library choices](docs/REDESIGN-DECISIONS.md).
The data end on **2026-08-21**; this is historical research, not live monitoring.

## Run the dashboard

From PowerShell in this directory:

```powershell
.\launch_research.ps1
```

Open `http://127.0.0.1:8511`. The launcher uses this copy's environment and binds
only to localhost. Stop with Ctrl+C. Select a historical date and inspect all
three pillars, the probability estimate, model alarm, external watch, every
crisis row, and the false-alarm record. See [viewer guide](docs/HOW-TO-RESEARCH.md).

## Reproduce the experiment

The installed `.venv` is ready on this computer. To rerun without overwriting
the first results:

```powershell
.\.venv\Scripts\python.exe scripts/run_prediction_experiment.py --out research_results/replication
.\.venv\Scripts\python.exe scripts/run_hazard_watch.py --results research_results/replication
.\launch_research.ps1 -Results research_results/replication
```

For a fresh environment with Python 3.12 and `uv`:

```powershell
uv venv --python 3.12 .venv
uv pip install --python .venv/Scripts/python.exe -r requirements-research.lock.txt
uv pip install --python .venv/Scripts/python.exe -e ".[dev,research]"
```

Run setup only when creating a fresh environment. The lock records the tested
versions; recreating these versions on another platform may require platform
compatible wheels. `arch` supplies the GJR-GARCH benchmark; no R bridge or
continuous-time Hawkes package is required by the new experiment.

## What changed

- Fixed composite uncertainty to include cross-regime covariance: `a.T @ P @ a`.
- Removed fictitious Kalman measurements during missing data and repeated
  assimilation of the same observation vintage; added an explicit time clock.
- Corrected intraday Lee–Mykland threshold normalization and made its default
  multiplicity window fixed so future appended bars cannot change old flags.
  Existing intraday/Hawkes snapshots were not regenerated by this repair.
- Added causal daily-tail Hawkes, fast/slow shrinkage RMT, and filtered variance
  Hamilton variants. Original pillar implementations remain in the copy.
- Added matured-label logistic forecasts, Student-t volatility benchmarks,
  chronological alert calibration, ablations, fit audits and probability scores.
- Added a separately attributed public-event watch, source register and replay.
- Isolated the default experimental database at port 5434; the forecasting
  experiment needs no database. The snapshot script explicitly reads the
  original source through a read-only transaction.

The RMT extension uses ten deterministic stock portfolios, not economic
sectors or the original 500-stock significance test. The daily-tail Hawkes
extension is not the original intraday jump model. Hamilton's high-volatility
state probability is not a crisis probability. Model differences are explicit
in [pillar notes](docs/PREDICTION-PILLARS.md).

## Evidence and constraints

[EXPERIMENT.md](EXPERIMENT.md) records the first design before forecast results.
[Mathematical amendments](docs/EXPERIMENT-MATH.md) explain corrections to the
copied historical specification. Prior evidence and failed configurations are
preserved, including the first `v1` run; `v1_verified` uses the same parameters
with hardened input handling. Data, model cutoffs and artifact hashes are saved.

The fixed historical false-alarm constraints do not guarantee future rates:
the combined onset model exceeds its calibration budget in the replay. The
external watch adds useful context for one event but the union policy is not
validated. Original adjusted data are not an immutable vintage archive; event
labels, survivorship coverage, and research selection remain limitations.

The next scientific requirement is a dated prospective record and independent
event definitions, with timestamped external credit, policy and health inputs.
Adding more parameters to these six remembered crises would not provide that
evidence. Current implementation and verification details are in
[VALIDATION.md](VALIDATION.md).
