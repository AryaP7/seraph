# Frozen news benchmark

Do not edit manifest.json. Each reviewer independently appends a JSON object to reviews.jsonl with document_id, document_hash, reviewer_id, reviewer_kind (human or agent), independent (true only if reviewed without model outputs or other labels), category, and labels. Labels require event_type, policy_status, action, targets (list of sector IDs), quantities (list with measure, old_level, new_level, delta, unit). Use null for absent numeric values. Record the text actually shown, not a linked body absent from the manifest. Two distinct independent human reviewers must agree on all fields; disagreements remain unresolved. No scores are generated by export.
